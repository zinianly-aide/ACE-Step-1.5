## 本机执行

先确认本地已有自己有权使用的 AMIGO 音频（实际长度 62.57068 秒）。

```bash
python3 scripts/fusion_d_intro.py \
  --amigo /path/to/amigo_63s.wav \
  --v3-dir audio-v3 \
  --out-dir /path/to/local/fusion-preview-D
```

需要 `ffmpeg`、`ffprobe` 和 Python `numpy`。不会调用 ACE-Step 推理或下载模型。

输出：

- `fusion_D_music_master.wav/.mp3`（纯音乐）
- `fusion_D_with_voice_master.wav/.mp3`（保留 v3 旁白）
- `fusion_D_metrics.json`（本机测得的 LUFS / True Peak / 交接点）
